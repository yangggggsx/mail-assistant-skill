## 下载与安装

下载 [mail-assistant-skill.zip](mail-assistant-skill.zip)，解压后阅读包内 README.md、RELEASE_READINESS.md 和 skills/mail-assistant/references/getting-started.md。

完整源码、测试、锁文件和文档目前在 ZIP 内；GitHub 根目录暂采用 ZIP 分发，尚未完成正常源码目录迁移。迁移方案见包内 SOURCE_IMPORT.md，已有远端历史将保留。

将解压后的 `mail-assistant-skill/skills/mail-assistant` 整个目录（含 LICENSE）复制到 `~/.codex/skills/mail-assistant`，重新加载技能。已有同名技能时先检查和备份。

示例：

> 使用 $mail-assistant，检查配置并协助在我自己的账户部署邮件助手。

安装 Skill 不会自动部署服务。需自行准备 Cloudflare、邮箱 OAuth、OpenAI 和 Pushover；账户注册和 OAuth 由本人完成。当前生成器仍要求目标 Outlook 日历账户，并生成两个 Queue 和 Images 绑定；分阶段验收不代表已经支持精简安装模式。

## 模型选择与自定义计划

邮件助手采用个人独立部署方式，使用者自行配置云资源、邮箱授权和模型服务。当前公开预览版的自动分类、摘要、翻译与日程提取仍固定调用 OpenAI 接口，可配置模型名称，但尚未实现并验收 DeepSeek、Kimi 等供应商的切换，不能直接替换 API 密钥使用。

后续拟支持自定义供应商、API 地址、密钥及按功能选择模型，例如使用一个模型处理邮件分类和翻译，另一个模型处理图片与 PDF。实际可用功能将取决于所选接口和模型的结构化输出、流式响应及文件处理能力；不支持的功能拟明确提示或允许关闭，不会默认把邮件转发给另一家服务商。相关 API 费用由部署者自行承担。这些属于计划能力，完成适配与真实接口验收后才会标为支持。

后台模型配置与“复制到 AI”的 App 入口相互独立：后者由网页复制、快捷指令打开 ChatGPT / Claude，再由用户手动粘贴发送。接入其他后台模型不会自动增加对应 App 入口，也不代表获得其 API 额度或 App 会员。

## 功能与范围

- Gmail / Outlook 收件、邮件类别与重要程度双维度分类、摘要、Pushover 推送和简报。
- 中文翻译、分类反馈、复制到 AI 的上下文与反馈；iPhone 上“复制并打开 ChatGPT / Claude”通过快捷指令打开 App，随后手动粘贴并发送。
- iPhone 快捷指令「加入待办」写入 Apple 提醒事项并回传结果。
- 邮件、PDF、图片及 HEIC/HEIF 提取会议、活动、截止日期等日程；可编辑预览后确认写入 Outlook 并核验。
- 课程关联更新和 Outlook JunkEmail 云端复查；不据此宣称所有邮箱垃圾箱均覆盖。

Gmail / Outlook 直接授权接入无需自动转发。其他邮箱可考虑转发到已接入邮箱，具体受服务商和组织政策限制，原邮件定位与垃圾箱覆盖需实测。

当前通知渠道为 Pushover。飞书尚未适配；需要处理认证、消息布局、操作链接及快捷指令返回目标，不能只替换 API URL。

## PDF／图片日程工具更新（2026-10-28）

通用文件提取在原文没有结束时间时，可按活动类型给出 AI 预计时长、理由和预计结束时间。篮球与足球可有不同建议，明确可能加时的赛事可建议更长占位；这些是可修改的建议，不是原文事实或实际完赛保证。已有结束时间优先使用原文；缺少开始日期／时间、全天、截止事项或无法合理判断时，不套用预计时长。课程关联模式暂保留原有时间处理。

有具体钟点的通用日程会按上传时选择的时区转换后预览；圣路易斯选择 `America/Chicago`，转换按日期处理夏令时。赛程的 LOCAL 是比赛所在地时间，ET 是东部时间，不能混用；提取提示要求有 ET 列时统一读取 ET，但复杂表格仍可能错读，需要核对原图。全天日期不跨时区平移。

预览新增「全选新增与更新」，仍需点击一次「确认加入 Outlook」。全选不自动选择删除，不跳过日期与时间校验。预计结束时间可以直接编辑，日历备注保留 AI 原建议的说明。旧预览不会自动重新提取；要应用新提取逻辑需重新上传，已写入或写入结果不确定时先核对日历，避免重复。

此更新包含云端工具源码；上传接口和快捷指令协议未变，现有上传快捷指令无需重装。独立部署者需要更新自己的 Worker，下载 ZIP 本身不会升级云端服务。

## iPhone 快捷指令

“复制到 AI”也有快捷指令配置：在 iPhone 上创建 `邮件助手-ChatGPT` 和/或 `邮件助手-Claude`，每个只放一个“打开 App”动作，选择对应的 ChatGPT 或 Claude；名称必须完全一致，可只配置自己使用的 App。网页先复制内容，快捷指令只打开 App，用户自行粘贴并发送；不会自动调用模型或发送邮件内容，也不会把正文放入跳转 URL。

“仅复制全部”不需要快捷指令，受浏览器剪贴板权限限制。复制失败时不会自动跳转；复制成功但未跳转时可用备用入口。没有提供这两个快捷指令的共享安装链接，按以上步骤手动创建即可。新手机实际流程仍待验收。

[安装「邮件助手-加入待办」](https://www.icloud.com/shortcuts/7a610bc2e6524944ad34449f66d94e11)。共享版本保留作者设备上的提醒事项列表引用，安装后必须在“添加提醒事项”动作里重新选择自己的「邮件待办」列表。保留快捷指令名称并安装 Pushover；从邮件助手的“加入待办”入口启动。

已做静态检查，未在新手机完成安装验收。PDF/图片上传快捷指令按包内 shortcuts.md 单独配置。创建日程或待办成功后默认不额外发送 Pushover 成功通知。
